How Credence is built on Solana

One Anchor program between the borrower, the lender and the LPs. Money only ever moves into a loan or the vault.

Borrower or curator

Buys gap protection

Before Friday's bell, for one loan or a whole book of loans.

↓ the premium goes to the vault
LPs

USDC vault

Underwrites the weekend. Earns premiums and the backstop's spread; idle cash is lent on Kamino.

Credence program

Prices, protects, pays

Reads the loan straight from the lender's own account, so nobody can feed it a fake position.

  • Gap Oracle: an on-chain account per stock, readable by any program
  • Gap Cover: priced on-chain from each stock's weekend history
  • Liquidation Shield: repays into the loan on Sunday night
  • Settlement: on the same price the lender liquidates on
  • Monday Backstop: buys what still liquidates, resells by auction
Lenders

Kamino · Jupiter Lend

Payouts go back through the lender's own repay instruction, signed by the vault's program address.

Prices

Lender's price + 24/7 price

The price the lender is frozen on, and the token's live weekend price from Pyth.

Keeper

Friday and Monday steps

Stores the close, runs the Shield and settlement. Anyone can run it.
