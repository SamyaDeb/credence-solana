# Data

Copied (files only, no history) from EVM Credence Finance, commit `cfd27566` (Oct 3, 2026),
`calibration/out/`: `scenarios/`, `joint/`, `sigma/`, `calendars/XNYS-*`, `backtest/`.
Source: Alpaca SIP data, Jan 2016 to Sept 25, 2026, free personal licence (not cleared for commercial use; see
the README, Known limits).

`onchain/` (generated by `scripts/`, task 1.5): 1,000-quantile sets and Q64.64 gap factors.

**No QQQ data.** The scenario sets and the joint set cover NVDA, AAPL, TSLA, COIN, MSFT, SPY, GOOGL, AMZN.
QQQ is a contributor to SPY's pooled `INDEX_ETF` set, but it has no own σ and no joint-set column. How QQQx is handled
is recorded in `data/onchain/assets.json` (`sigmaSource`) and `scripts/src/gen-onchain.ts`.
